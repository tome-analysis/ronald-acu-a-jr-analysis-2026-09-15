# Ronald Acuña Jr. 打者分析

## 概要

MLB選手ロナルド・アクーニャJr.の2023年の打撃・走塁データを用いて、
41本塁打・73盗塁を記録した異次元の2023年について分析しました。

特に、2023年に記録した73盗塁に注目し、
出塁能力や盗塁成功率、Sprint Speedなどから走塁面を分析するとともに、
Exit Velocity、Hard-Hit%、Barrel%、xSLGなどから、
41本塁打を生み出した打球の質について分析しました。

## 分析テーマ

### 1. 41本塁打・73盗塁を記録した2023年

2023年の打率、出塁率、長打率、OPS、本塁打数、盗塁数、四球数などから、
41本塁打・73盗塁を記録したアクーニャJr.の
2023年シーズンの打撃成績と特徴を整理しました。

### 2. 73盗塁を可能にした出塁能力と走力

2023年の出塁率や四球数、盗塁数、盗塁成功率を確認し、
さらにSprint SpeedからアクーニャJr.の走力を分析しました。

高い出塁能力によって盗塁の機会を作り、
高い盗塁成功率と走力を生かして73盗塁を記録した点に注目しました。

### 3. 走力だけではない、圧倒的な打球の質

Exit Velocity、Hard-Hit%、Barrel%、xSLGなどのStatcast指標を用いて、
41本塁打を生み出したアクーニャJr.の打球の質を分析しました。

特に、Hard-Hit%やBarrel%がMLB平均を大きく上回っていた点に注目し、
アクーニャJr.が強い打球を多く生み出し、
長打につながりやすい質の高い打球を高い割合で打っていたことを考察しました。

## 目的

PythonやSQLを用いたデータ取得・加工を行い、
MLBの打撃・走塁データから選手の特徴や強みを分析することを目的としています。
