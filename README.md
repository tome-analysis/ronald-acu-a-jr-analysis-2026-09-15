# Ronald Acuña Jr. 打者分析

## 概要

MLB選手ロナルド・アクーニャJr.の2023年シーズンの打撃・走塁データを用いて、41本塁打・73盗塁を記録したシーズンの特徴を分析しました。

特に、出塁能力や走力と盗塁数の関係、Statcast指標から見た打球の質に注目し、アクーニャJr.の打撃・走塁の強みを複数の観点から考察しました。

## 分析内容と結果

### 1. 41本塁打・73盗塁を記録した2023年

打率、出塁率、長打率、OPS、本塁打数、盗塁数、四球数などを用いて、2023年シーズンの打撃・走塁成績を整理しました。

### 2. 73盗塁を可能にした出塁能力と走力

出塁率、四球数、盗塁数、盗塁成功率に加え、Sprint Speedを用いて走塁面を分析しました。

出塁能力によって盗塁の機会を作ることと、走力や盗塁成功率の両面から、73盗塁を記録した背景を考察しました。

### 3. 走力だけではない、圧倒的な打球の質

Exit Velocity、Hard-Hit%、Barrel%、xSLGなどのStatcast指標を用いて、打球の質を分析しました。

打球速度や強い打球の割合、長打の期待値に関する指標を組み合わせ、41本塁打を記録した打撃の特徴を考察しました。

## 分析で意識したこと

* 複数の指標を組み合わせ、選手の強みを多角的に捉えること
* データから確認できる事実と、そこから導く考察を区別すること
* 分析結果を整理し、野球に詳しくない読者にも伝わる形で発信すること
